# amazingThings 🌌✨

A curated collection of visually stunning, interactive simulations, creative coding experiments, 3D visualizations, and interactive WebGL experiences.

---

## 🚀 Projects Overview

### 🪐 1. Galaxy Simulation (`galaxy_simulation.py`)
- **Type:** Python (Pygame / NumPy / ModernGL / Math)
- **Description:** A real-time, interactive 3D spiral galaxy simulation featuring realistic galactic rotation curves, dense stellar nucleus glow, dust lanes, and dynamic orbital mechanics.
- **Controls:** Mouse drag to rotate view, scroll to zoom in/out, keyboard shortcuts for visual presets and particle density.

### 🕳️ 2. Black Hole Simulation (`black_hole_simulation.py`)
- **Type:** Python (NumPy / Pygame)
- **Description:** An interactive physics-based simulation of a supermassive black hole. Simulates gravitational lensing, event horizon, photon ring, relativistic Doppler beaming, and a swirling accretion disk.

### 🌍 3. Cinematic 3D Earth (`cinematic_3d_earth.html`)
- **Type:** WebGL / Three.js / HTML5
- **Description:** A photorealistic, cinematic 3D Earth visualization rendered in the browser. Features multi-layer atmospheric scattering, rotating clouds, daylight textures, and glowing nighttime city lights.
- **How to run:** Open directly in any modern web browser.

### ⚡ 4. Plasma Particle Sphere (`plasma_particle_sphere.html`)
- **Type:** WebGL / Three.js / HTML5
- **Description:** A futuristic plasma sphere generated with thousands of reactive particles, electric arcs, glowing energy filaments, and responsive camera motion.
- **How to run:** Open directly in any modern web browser.

### 🎵 5. Audio Visualizer (`audio_visualizer.html`)
- **Type:** Web Audio API / HTML5 Canvas / WebGL
- **Description:** An interactive real-time music and microphone visualizer with dynamic frequency spectrum analyzers, waveforms, reactive particle bursts, and customizable color themes.
- **How to run:** Open in any modern web browser, select an audio file or enable microphone input.

### 💻 6. Sci-Fi System Diagnostics (`fake_system_diagnostics.py`)
- **Type:** Python Terminal UI
- **Description:** A Hollywood-style terminal diagnostic scanner and cybernetic telemetry interface.

## 🛠️ Setup & Installation

### Python Projects
1. Make sure Python 3.9+ is installed.
2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run any simulation:
   ```bash
   python galaxy_simulation.py
   # or
   python black_hole_simulation.py
   ```

### Web / HTML Projects
Simply open any `.html` file (`cinematic_3d_earth.html`, `plasma_particle_sphere.html`, `audio_visualizer.html`) in Google Chrome, Microsoft Edge, Firefox, or any modern web browser.
